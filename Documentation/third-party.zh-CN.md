# 第三方软件与分发

请阅读插件[第三方声明](../THIRD_PARTY_NOTICES.md)。插件分发包含 CEF SDK、编译好的浏览器运行库及资源，Helper 是与之配套的独立 EXE。WebUIStudio 单独分发，并包含它自己的依赖许可材料。

示例使用未修改的本地 Geist、Geist Mono 与 Noto Sans SC 字体，以及 Vue 和 three.js。原始许可证随插件提供，并复制到网页生产产物。复用示例网页时保留这些文件。

展厅的字体展室还列出了九种 Windows 通常自带的字体，例如 Segoe UI 和微软雅黑。它们只按名称引用：插件里没有这些字体的任何文件，只有在已经安装了该字体的机器上才会显示。你自己的界面依赖哪些字体，请在许可允许的前提下随界面一起分发。

示例的其余内容均为原创并由程序生成：楼阁、太阳系、星系、黑洞和小行星带完全由代码搭建、由程序着色，楼阁的贴图在运行时绘制到画布上，配乐与影片由 `Content/UI/WebUI/Showcase/tools` 中的脚本合成和渲染。其中不包含素材库影像、采样音频或私有游戏资产。基础几何体和示例游戏逻辑不依赖私有游戏资产。

Fab 插件包、本地安装包、公开示例和游戏包体的内容不同：

| 交付物 | 包含内容 |
| --- | --- |
| Fab 插件 | Unreal 源码、插件资产、浏览器 SDK/运行材料、网页生产资源、文档和准备脚本；配套 EXE 单独获取 |
| 本地安装包 | 完整插件及准备好的配套 EXE |
| 公开示例 | 蓝图示例工程及说明，商业插件需单独安装 |
| 游戏包体 | Cook 资产、需要的网页产物、Helper、CEF 运行库和声明，不包含 Studio |

Fab 审核是独立的平台流程。本地编译、GitHub Release 或游戏运行成功都不表示已经取得 Fab 审核通过。支持范围以实际发行说明中的引擎和平台版本为准。
